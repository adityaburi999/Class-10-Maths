# Quadratic Equations: 50 Important Questions with Solutions (Class 10)

1. **Question:** Solve \(x^2-5x+6=0\).


   **Solution:** \((x-2)(x-3)=0, so x=2,3\).

2. **Question:** Solve \(2x^2+7x+3=0\).


   **Solution:** \((2x+1)(x+3)=0, so x=-\frac12,-3\).

3. **Question:** Solve \(x^2-9=0\).


   **Solution:** \((x-3)(x+3)=0, so x=\pm3\).

4. **Question:** Solve \(3x^2-12x=0\).


   **Solution:** \(3x(x-4)=0, so x=0,4\).

5. **Question:** Solve \(x^2+10x+25=0\).


   **Solution:** \((x+5)^2=0, so x=-5\) (repeated).

6. **Question:** Solve \(4x^2-1=0\).


   **Solution:** \((2x-1)(2x+1)=0, so x=\pm\frac12\).

7. **Question:** Solve \(x^2-4x-5=0\).


   **Solution:** \((x-5)(x+1)=0, so x=5,-1\).

8. **Question:** Solve \(6x^2-x-2=0\).


   **Solution:** \((3x-2)(2x+1)=0, so x=\frac23,-\frac12\).

9. **Question:** Solve \(x^2+3x-18=0\).


   **Solution:** \((x+6)(x-3)=0, so x=-6,3\).

10. **Question:** Solve using quadratic formula: \(x^2-2x-7=0\).


    **Solution:** \(x=\frac{2\pm\sqrt{4+28}}{2}=1\pm2\sqrt2\).

11. **Question:** Solve \(2x^2-4x+1=0\).


    **Solution:** \(x=\frac{4\pm\sqrt{16-8}}{4}=1\pm\frac{\sqrt2}{2}\).

12. **Question:** Solve \(3x^2+2x+5=0\).


    **Solution:** \(D=4-60=-56<0\). No real roots.

13. **Question:** Find nature of roots of \(x^2-6x+9=0\).


    **Solution:** \(D=36-36=0\). Equal real roots.

14. **Question:** Find nature of roots of \(x^2+4x+8=0\).


    **Solution:** \(D=16-32=-16<0\). No real roots.

15. **Question:** Find \(k\) so that \(x^2+kx+9=0\) has equal roots.


    **Solution:** \(k^2-36=0, so k=\pm6\).

16. **Question:** Find \(k\) so roots of \(x^2+(k-1)x+4=0\) are real.


    **Solution:** \((k-1)^2-16\ge0, so |k-1|\ge4, so k\le-3\) or \(k\ge5\).

17. **Question:** If roots are 2 and 5, form equation.


    **Solution:** \(x^2-7x+10=0\).

18. **Question:** If roots are \(-3\) and \(\frac12\), form equation with integer coefficients.


    **Solution:** \((x+3)(2x-1)=0, so 2x^2+5x-3=0\).

19. **Question:** Solve \(x^2-7x+12=0\).


    **Solution:** \((x-3)(x-4)=0, so x=3,4\).

20. **Question:** Solve \(5x^2-20x+15=0\).


    **Solution:** Divide by 5: \(x^2-4x+3=0, so x=1,3\).

21. **Question:** Solve \(9x^2-30x+25=0\).


    **Solution:** \((3x-5)^2=0, so x=\frac53\).

22. **Question:** Solve \(x^2+2\sqrt3x+3=0\).


    **Solution:** \((x+\sqrt3)^2=0, so x=-\sqrt3\).

23. **Question:** Solve \(x^2-\sqrt5x+1=0\).


    **Solution:** \(x=\frac{\sqrt5\pm1}{2}\).

24. **Question:** Solve \(x^2-\frac{5}{2}x+1=0\).


    **Solution:** Multiply by 2: \(2x^2-5x+2=0=(2x-1)(x-2)\). \(x=\frac12,2\).

25. **Question:** Solve \(x(x-4)=5\).


    **Solution:** \(x^2-4x-5=0, so x=5,-1\).

26. **Question:** Solve \((x+2)(x-3)=10\).


    **Solution:** \(x^2-x-6=10, so x^2-x-16=0, so x=\frac{1\pm\sqrt{65}}{2}\).

27. **Question:** Solve \(\frac1x+\frac1{x-2}=\frac34\), \(x\neq0,2\).


    **Solution:** \(\frac{2x-2}{x(x-2)}=\frac34, so 8x-8=3x^2-6x, so 3x^2-14x+8=0, so x=4,\frac23\).

28. **Question:** Solve \(x^2=6x-8\).


    **Solution:** \(x^2-6x+8=0=(x-2)(x-4), so x=2,4\).

29. **Question:** Solve \(2x^2+3x=2\).


    **Solution:** \(2x^2+3x-2=0=(2x-1)(x+2), so x=\frac12,-2\).

30. **Question:** Solve \(x^2+1=2x\).


    **Solution:** \((x-1)^2=0, so x=1\).

31. **Question:** Product of two consecutive positive integers is 56. Find numbers.


    **Solution:** Let \(x(x+1)=56, so x^2+x-56=0, so x=7\). Numbers 7 and 8.

32. **Question:** Area of rectangle is 96 m², length 4 m more than breadth. Find dimensions.


    **Solution:** \(b(b+4)=96, so b^2+4b-96=0, so b=8\) (positive), length 12.

33. **Question:** A number exceeds its reciprocal by \(\frac{15}{4}\). Find number.


    **Solution:** \(x-\frac1x=\frac{15}{4}, so 4x^2-15x-4=0, so x=4,-\frac14\).

34. **Question:** If roots of \(x^2-5x+k=0\) are reciprocal, find \(k\).


    **Solution:** Product \(=1=\frac{k}{1}, so k=1\).

35. **Question:** If one root of \(x^2-3x-10=0\) is \(m\), find other root.


    **Solution:** Roots are \(5,-2\). Other root depends on \(m\): if \(m=5\), other \(-2\), vice versa.

36. **Question:** Find \(k\) if \(x=2\) is root of \(x^2+kx+6=0\).


    **Solution:** \(4+2k+6=0, so k=-5\).

37. **Question:** Solve \(4x^2+4x+1=0\).


    **Solution:** \((2x+1)^2=0, so x=-\frac12\).

38. **Question:** Solve \(3x^2-13x+4=0\).


    **Solution:** \((3x-1)(x-4)=0, so x=\frac13,4\).

39. **Question:** Solve \(7x^2+2x-1=0\).


    **Solution:** \((7x-1)(x+1)=0, so x=\frac17,-1\).

40. **Question:** Solve \(x^2-11x+24=0\).


    **Solution:** \((x-3)(x-8)=0, so x=3,8\).

41. **Question:** Find roots of \(x^2+px+q=0\) if sum is \(-4\), product is 3.


    **Solution:** Equation \(x^2+4x+3=0, so x=-1,-3\).

42. **Question:** Find \(k\) so that \(2x^2+kx+8=0\) has no real roots.


    **Solution:** \(k^2-64<0, so -8<k<8\).

43. **Question:** Solve \(\frac{x-1}{x+1}=\frac{x+3}{x-3}\), \(x\neq\pm1,3\).


    **Solution:** Cross-multiply: \((x-1)(x-3)=(x+3)(x+1), so x^2-4x+3=x^2+4x+3, so x=0\).

44. **Question:** Solve \(x^2-2(\sqrt2)x+2=0\).


    **Solution:** \((x-\sqrt2)^2=0, so x=\sqrt2\).

45. **Question:** Solve \(x^2-3x+\frac94=0\).


    **Solution:** \((x-\frac32)^2=0, so x=\frac32\).

46. **Question:** Solve \(2x^2-5x+2=0\).


    **Solution:** \((2x-1)(x-2)=0, so x=\frac12,2\).

47. **Question:** Solve \(3x^2+x-10=0\).


    **Solution:** \((3x-5)(x+2)=0, so x=\frac53,-2\).

48. **Question:** Solve \(x^2+7x+12=0\).


    **Solution:** \((x+3)(x+4)=0, so x=-3,-4\).

49. **Question:** Solve \(x^2-\frac{1}{x}=0\), \(x\neq0\).


    **Solution:** Multiply by \(x\): \(x^3-1=0, so x=1\) (real).

50. **Question:** Solve \(x^4-5x^2+4=0\).


    **Solution:** Let \(y=x^2\). \(y^2-5y+4=0, so y=1,4\). So \(x=\pm1,\pm2\).
